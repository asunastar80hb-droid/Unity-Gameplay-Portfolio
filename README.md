# Unity Gameplay Portfolio

A personal Unity project created to showcase gameplay programming, game systems, mechanics, and interactive prototypes.

## About

This project serves as a collection of practical Unity development samples.

Each scene focuses on a specific gameplay feature, system, or programming concept and is designed to demonstrate its implementation in a playable environment.

## Project Goals

* Showcase practical Unity gameplay programming skills
* Demonstrate different gameplay systems and mechanics
* Keep each system organized and reusable
* Provide playable examples alongside source code
* Document the implementation and technical decisions behind each sample

## Planned Samples

The project will gradually include different gameplay and system demonstrations, such as:

* Character Controller
* Movement & Interaction
* Combat Systems
* Inventory System
* Shop & Currency
* Dialogue System
* Puzzle Systems
* Mini Games
* Enemy AI
* Save & Load
* Level & Stage Management

## Technologies

* Unity
* C#
* Git
* GitHub

## Project Structure

Each sample is organized as a separate scene and focuses on a specific gameplay feature or system.

Additional documentation, screenshots, and implementation details will be added as the project develops.
